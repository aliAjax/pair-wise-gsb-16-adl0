# hxwl-01 验配台账

门店听力师的验配台账：初配建档、复调对照、编号修订留痕。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5101

## 功能

- **初配建档**：录客户、耳别、听力数据（气导/骨导/言语识别率）与助听器型号，确认后生成 R1
- **复调**：自动带出上次确认的增益与反馈等级；任一频段增益变化超过 6dB 或反馈等级升高时，必须填写调整原因
- **编号修订**：确认后的单据只读、不可覆盖，新调整只能以 R2、R3… 接续追加
- **待确认草稿**：同一客户同耳只保留一份草稿；换单时自动暂存回本台账，各单草稿互不串台
- **查找**：重开页面后按客户姓名 + 耳别检索台账（localStorage 持久化）

## 代码结构（资料 / 校验 / 存储 分层）

```
src/
  domain/
    types.ts        # 资料：台账、修订、草稿的数据模型
    validation.ts   # 校验：字段范围、超 6dB / 反馈升高的原因必填规则
  storage/
    ledgerStore.ts  # 存储：台账与草稿的 localStorage 读写、追加式修订
  App.tsx           # 页面：查找、初配、复调、修订历史
```
